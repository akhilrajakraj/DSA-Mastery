# DSA Mastery Roadmap

This is the master sequence for the repository.

## Study Rule

Do not advance because a checklist says so. Advance when the current topic can be explained, implemented, analyzed, and applied to unfamiliar problems.

## Sequence

00 Foundations → 01 Arrays → 02 Strings → 03 Hashing → 04 Two Pointers → 05 Sliding Window → 06 Stack → 07 Queue → 08 Linked List → 09 Binary Search → 10 Sorting → 11 Trees → 12 BST → 13 Heaps → 14 Graphs → 15 Greedy → 16 Backtracking → 17 Dynamic Programming → 18 Trie → 19 DSU → 20 Advanced → 21 Mixed Practice → 22 Interview Practice.

## Topic Completion Gate

Before marking a topic complete:

- [ ] Concepts understood
- [ ] Core implementation written from scratch
- [ ] Complexity understood
- [ ] Easy problems solved independently
- [ ] Medium problems solved independently
- [ ] At least one unfamiliar/mixed problem attempted
- [ ] Mistakes documented
- [ ] Missed problems reattempted
