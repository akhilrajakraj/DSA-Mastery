# DSA Mastery

> A structured, long-term journey to master Data Structures & Algorithms through understanding, implementation, pattern recognition, deliberate practice, revision, and reattempts.

## 🎯 Goal

Build strong algorithmic problem-solving ability—not just a large solved-problem count.

The primary language is **Python 3**.

## 🧭 How This Repository Works

```text
Learn Concept
     ↓
Implement From Scratch
     ↓
Analyze Time & Space Complexity
     ↓
Solve Guided Problems
     ↓
Recognize Patterns on New Problems
     ↓
Blind / Mixed Practice
     ↓
Record Mistakes
     ↓
Reattempt Later
     ↓
Master the Topic
```

## 🧠 Mastery Standard

A problem is **not** mastered simply because the code passes once.

A problem/topic is approaching mastery when you can:

- identify the likely technique from a new problem;
- explain why the approach works;
- implement it without copying;
- analyze time and space complexity;
- handle important edge cases;
- explain alternative approaches and trade-offs;
- re-solve previously missed problems after a delay.

## 🔁 Problem Difficulty

- **Easy** — learn the basic technique.
- **Medium** — develop independent reasoning.
- **Hard** — combine techniques and optimize.
- **Mixed** — the topic/pattern is deliberately hidden.

## 🚀 Start Here

1. Read [`roadmap/README.md`](roadmap/README.md).
2. Complete [`roadmap/00-foundations.md`](roadmap/00-foundations.md).
3. Work through the numbered topics in order.
4. Maintain pattern notes while solving.
5. Record every meaningful mistake.
6. Reattempt missed problems before moving on.
7. Use mixed practice regularly to test genuine problem recognition.

**Principle:** consistency beats intensity, understanding beats memorization, and re-solving beats merely moving on.
